# Memory

Anything remembered. It might be something that was said or happened, something inferred from that, or a name that other memories gather around, such as a person, a project or a topic. These are all the same kind of thing. What separates a raw observation from a belief or a concept is the memory's evidence and how it's connected, not a declared type.

## Invariants

- **A memory's content is never edited.** When a memory turns out to be wrong or out of date, a new memory supersedes it. The old one stays in the mind's history and can be recovered, marked as superseded.
- Every memory has a confidence, and that confidence is earned from evidence. It's never assumed, and never granted just because something was written down.
- Confidence answers two questions: *was this right when it was last checked*, and *is it still right now*. Nothing renews itself. Without fresh evidence, confidence fades at a rate set by how quickly that kind of thing changes. A name barely fades, a preference slowly does, and a plan expires.
- **Confidence is never overstated.** However a memory is shown to an agent, it never implies more certainty than its evidence supports.
- How well a memory matches a question and how much it's believed are different things. They're never merged into one number or described in the same words.
- Recalling or using a memory never makes it more believed.
- Direct observations can be wrong too, for example misattributed or mistranscribed. They start with the strongest footing of anything in the mind, but they aren't beyond question.
- A memory can say what would make it stop being true. That condition is itself a memory, associated with the one it would defeat.
- A memory nothing reaches fades from recall but isn't destroyed. The only true deletion is an explicit request to forget.
