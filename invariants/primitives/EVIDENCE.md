# Evidence

The mind's notebook. Each entry records that something observed, confirmed, contradicted or superseded a memory, and where that came from. Memories are fallible and associations fade, so evidence is how a mind stays accountable anyway, the way people keep notes because they know their memory won't. It's the one part of a mind that sits outside the web of associations.

## Invariants

- **Evidence is never edited.** Entries are only ever added. The only removal is an explicit request to forget, which takes the memory and its evidence together.
- Every entry names its source and the moment it came from. The source might be:
  - the user, speaking unprompted
  - the user, answering a question
  - a tool or file
  - the web
  - another agent
  - the agent's own inference
- Sources aren't equal. What the user says outweighs what the agent infers, and a direct answer to a direct question outweighs everything.
- An agent's own use, repetition or echo of a memory is not evidence. Repeated reports of the same thing from the same source count once.
- Silence is weak evidence at best. A question nobody answered is no evidence at all.
- A memory's confidence can be rebuilt entirely by replaying its evidence. The evidence is the record, and confidence is only a summary of it.
- **"Why do you believe this?" always has an answer**, taken from evidence alone, even after the associations that once led to the memory's source have faded.
