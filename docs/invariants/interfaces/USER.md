# User

The person the agent serves. They are the most trusted source of evidence, and the only one who can say for certain whether a memory about them is still true.

## Invariants

- **The user's own words outweigh every other source.** A direct answer to a direct question outweighs everything.
- The user is asked to reconfirm a memory only when being wrong would cost more than the interruption, and never more often than the limits allow.
- The user never has to learn Tapestry or run it. Everything happens through the agent, in ordinary conversation.
- The user can always ask:
  - what the agent remembers about something;
  - why it believes it;
  - to correct it;
  - to forget it.
- A correction from the user supersedes the memory. It's never argued with.
- A request to forget is honoured completely.
- Nothing the user says is attributed to anyone else, and nothing anyone else said is attributed to the user.
