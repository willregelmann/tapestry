# Change

Something the agent deliberately did to the shape of its [mind](MIND.md), kept so it can be seen and undone: a [topic](TOPIC.md) created, described, moved or taken into another, [memories](MEMORY.md) filed elsewhere, an [association](ASSOCIATION.md) made or adjusted by hand. Each says who made it, when, in which session, why, and what was there before and after.

An agent may change its own mind because every change is on the record and can be put back. Undoing a change is itself a change, so the record only grows.

What the mind learns is not a change. A fact noted or drawn from a conversation, a correction, and an association strengthening with use are learning, each with its own record in [evidence](EVIDENCE.md). Deciding to make a change takes judgment, so the agent makes that call. That it is recorded, and how it is undone, are fixed.

## Invariants

- **Every deliberate change is recorded as it is made.** A change that can't be recorded isn't made, and nothing of this kind is done to a mind any other way.
- **A recorded change is never rewritten or removed.** Undoing one adds a change that puts back what was there, and that one can be undone in turn.
- **Undoing reaches only what the change touched.** Everything learned or changed since stays as it is.
- An undo applies only where the mind is still as the change left it. Otherwise it changes nothing and says what is in the way.
- Everything one session changed can be undone together. A change that can't be undone is passed over and named, and the rest are still undone.
- **A change never holds what a memory says.** It names memories by number, and when a memory is forgotten the reasons given for changing it go too. Forgetting is not a change and can't be undone.
- A change to how a memory is filed is still recorded as evidence on that memory, and so is undoing it.
- The owner can see every change, in the same words the agent is given.
