# Association

A directed connection from one memory to another, with a strength between 0 and 1. The strength is how strongly recalling the first should bring the second to mind. Associations are how one memory leads to another: a question reaches a few memories directly, and associations carry recall outward from there, to memories that share no words with the question.

An association is born when a fact is written, and use decides what becomes of it. The agent or the owner can also make one by hand between memories the mind already holds, or strengthen or weaken one, as a [change](CHANGE.md) with its reason. Facts written from the same moment are linked to each other, and a new fact is linked to the memories it builds on or corrects. After that, two memories prove useful together when both were in mind at a moment that taught something new.

Associations decide what comes to mind, never what can be seen. What a lookup can see is set by [topics](TOPIC.md) alone.

Deciding which memories a new fact builds on takes judgment, so whoever writes the fact makes that call: the agent noting it, or a model drawing it from an [episode](EPISODE.md). Deciding that two memories already held belong together takes judgment too, and the agent or the owner makes that call. That facts written from one moment are linked to each other is fixed, and so is that an association made by hand is recorded.

## Invariants

- **Associations carry no labels.** There's only one kind. Meaning lives in the memories, and in an association's direction and strength.
- Direction matters. The strength from A to B is independent of the strength from B to A.
- **Every association is born with a fact, or made by hand as a recorded change.** A fact is linked, as it's written, to the others written from the same moment and to the memories it builds on or corrects. Between memories that already exist, only the agent or the owner makes one, on purpose, with a reason, and it can be undone.
- An association made by hand is like any other from then on: use strengthens it and disuse weakens it.
- **Strength governs recall, never belief.** A strong association never makes either memory more believed.
- Apart from a change made by hand, an association strengthens only when both its memories were in mind at a moment that taught something new. Being recalled together isn't enough on its own.
- Associations weaken without use. Nothing is severed outright: a weak association becomes hard to follow but isn't gone.
- The total strength flowing into any one memory is bounded, so no memory can come to dominate recall just by being popular.
- **An association never makes a memory visible.** Associations exist only within a single mind and can cross topics, but recall follows one only when both ends are in a topic being searched.
